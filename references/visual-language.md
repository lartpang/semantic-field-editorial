## Editorial illustration principle

Create a finished editorial illustration with a distinctive house aesthetic. The document informs the artwork but does not dictate a one-to-one inventory of visible content. Favor visual metaphor, omission, compression, ambiguity, and compositional invention. Do not make a diagram, infographic, slide, concept map, or literal scene unless the assigned job explicitly requires explanation.

Semantic Field is a visual language, not an encoding scheme. Anchor, Trace, Void, and Echo should be experienced as form, movement, absence, and rhythm before they are interpreted as concepts.

## Signature

> ONE ANCHOR + ONE TRACE + ONE VOID + ONE ECHO

The image should normally contain at least three of these four roles. Treat this as a family resemblance, not a checklist or four-part layout.

### Anchor

The dominant semantic mass.

Possible forms:

- cut disc
- ring
- slab
- layered band
- soft geometric mass
- bounded field
- stepped structure
- elongated tapered form

The anchor is not a logo. Its geometry must derive from the document's central relation.

### Trace

The directional structure.

Possible forms:

- line
- arc
- orbit
- axis
- path
- cut
- flow
- sequence
- return loop

The trace expresses causality, time, transition, comparison, recursion, or argument.

### Void

The meaningful absence.

Possible forms:

- aperture
- slit
- gap
- missing corner
- open ring
- interrupted field
- unusually large negative-space zone

Void is not empty decoration. It carries uncertainty, distance, boundary, incompleteness, pause, or contrast.

### Echo

The restrained repetition.

Possible forms:

- dot matrix
- bars
- tiles
- steps
- nodes
- short lines
- layered repeats
- progressively thinning marks

Echo is ideal for accumulation, plurality, iteration, residue, feedback, and after-effect.

## Base palette

```text
Background  #F3EFE7
Ink        #1E1E1B
```

Accent bank:

```text
Ember      #D56845
Mineral    #5F7686
Moss       #6F7B63
Violet     #8879A8
Ochre      #C39A4B
```

Use one primary accent per figure. A pale derivative is allowed. A second full accent requires a genuine semantic opposition.

## Spatial rules

- target 55–75% visually quiet area
- maximum three major visual groups
- favor asymmetric balance
- avoid evenly distributed auto-layout
- allow large relational distances
- use near-touching elements only when tension is semantically justified
- place the dominant visual idea where cropping will not destroy it

## Texture

Allowed only inside selected forms:

- sparse dry-screenprint speckle
- delicate stipple
- short hatch
- slightly imperfect pigment edge

Avoid full-background texture.

## Typography

Use as little text as possible.

Header:
- normally no embedded title
- 0–6 words maximum if text is required

Summary:
- short labels only

Explanatory:
- exact labels, numbers, equations, or symbols when necessary

Atmosphere:
- no text by default

## Semantic distance

```text
1 structural diagram
2 conceptual explanation
3 editorial abstraction
4 atmospheric abstraction
5 nearly non-representational
```

Recommended defaults:

```text
Header       3
Summary      2.5
Explanatory  1–2
Atmosphere   4
```

## Semantic mapping

```text
hierarchy      scale difference, nesting
causality      directed trace
feedback       loop or orbit
accumulation   clustering, layering, increased density
decay          thinning, interrupted continuity
divergence     one-to-many split
convergence    many-to-one movement
contrast       opposing fields or masses
threshold      boundary or slit
uncertainty    aperture, broken edge, unresolved void
preservation   persistent mark or baseline
translation    same relation rebuilt with another mark family
time           ordered states and spacing
tension        off-axis near-collision
harmony        measured alignment
fragmentation  separated pieces
emergence      dispersed marks condensing
diffusion      mass dissolving into echoes
inversion      mirror or directional reversal
layering       overlapping flat planes
```

## Index Marks

A recurring Semantic Field micro-motif:

- two or three short ticks
- tiny crosshair
- partial registration line
- short measured baseline
- offset node

They imply observation and calibration without pretending to be actual measured data.

Use sparingly.

## Anti-slop

Never default to:

- glowing AI brain
- robot head
- handshake
- light bulb
- generic skyline
- circuit-network halo
- glassmorphism
- blue-purple glow
- fake dashboards
- gears
- puzzle pieces
- random equations
- random dot fields
- generic stock icons
- decorative English microcopy
- poster slogans
- slide-deck card layouts

The result should feel like an editorial artwork built from the document's internal structure.
