# 生成提示词

四张图使用内置 ImageGen 生成，并共享 `visual-dna.json` 中的视觉系统。

## 01 — 题图

Use case: stylized-concept
Asset type: 中文技术长文题图，2:1 横幅
Primary request: 为“神经网络：从线性结构到可学习非线性”创作一张独立、克制的 Semantic Field 编辑插图。画面左侧只有数条完全平行、等距、笔直的近黑轨迹，代表同质线性传递；它们进入一个巨大的灰紫色开缝场域。狭缝是关键空缺。穿过狭缝后，同一组轨迹变成少量彼此不同但受控的平滑曲线，随后在远端重新形成可计算的秩序。两枚小型偏移节点跨在第一处弯曲两侧，少量短刻度构成回声。表现“函数形状可以被学习”，而不是画神经网络示意图。
Style/medium: 原创现代 Semantic Field 编辑插图，平面几何与轻微干式丝网颜料边缘，冷静、精确、有出版感
Composition/framing: 精确 2:1 横图，非对称，55–70% 留白，最多三个视觉组，重要元素处于安全裁切区域
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，唯一强调色灰紫 #8879A8
Text: 无文字、无字母、无数字、无公式
Constraints: Anchor/Trace/Void/Echo 自然融入；线性到非线性的变化清楚，但不是流程图；轨迹无箭头
Avoid: 大脑、神经元图标、发光网络、线路板、机器人、节点连线海报、矩阵、随机公式、坐标图、箭头标签、霓虹渐变、玻璃拟态、logo、水印

## 02 — 非线性从节点迁移到边

Use case: stylized-concept
Asset type: 中文技术文章概念解释插图，3:2
Primary request: 准确而克制地表达“非线性前置到边上”。三条近黑输入轨迹先各自经过一段不同形状的灰紫可学习曲线，再汇入一个极简单的近黑聚合节点；节点自身保持安静、只负责汇聚，随后输出一条直线。每段紫色曲线都位于连接路径上，而不是包围节点。节点旁保留一个明显的空白缺口，暗示固定后置激活不再是唯一非线性来源。第一段弯曲两侧出现两枚偏移小节点。
Style/medium: 原创 Semantic Field 解释性编辑插图，精确平面几何，灰紫曲线带有极轻丝网颗粒
Composition/framing: 精确 3:2 横图，左侧分散、右侧汇聚，大量静区，一条清晰阅读路径，不超过三个视觉组
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，灰紫 #8879A8
Text: 无文字、无字母、无数字、无公式
Constraints: 紫色非线性必须明确发生在边/轨迹上；汇聚节点不可被画成激活函数；无箭头
Avoid: 标准神经网络球状节点阵列、电路图、流程框、公式、标签、坐标轴、发光、logo、水印、装饰性点阵

## 03 — 局部样条与全局函数

Use case: stylized-concept
Asset type: 中文技术文章章节概要插图，3:2
Primary request: 表达两类函数逼近的对仗与取舍，不表达谁绝对更优。同一条近黑目标曲线横贯画面，在中央空白狭缝处被分成两种构造语言：左侧由数个短小、局部重叠的灰紫弧片逐段贴合，局部可独立调整；右侧由一条完整、连续、全局作用的灰紫长带托住整段曲线。两边拥有相近的视觉重量，中央空缺承担从局部几何插值到全局代数函数的转换。两枚偏移小节点位于狭缝边缘。
Style/medium: 原创 Semantic Field 编辑插图，平面抽象、克制的数学气质、局部轻微颜料边缘
Composition/framing: 精确 3:2 横图，左右不机械对称但权重平衡，60% 左右留白，不使用比较表格
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，灰紫 #8879A8
Text: 无文字、无字母、无数字、无公式
Constraints: 清楚保留“局部片段控制”与“全局连续函数”差异；不暗示全局函数无条件优于样条；无箭头
Avoid: 坐标轴、图例、公式、表格、对勾叉号、排行榜、PPT 卡片、发光、logo、水印

## 04 — 从绝对异质到分组共享

Use case: stylized-concept
Asset type: 中文技术文章章节概要插图，3:2
Primary request: 表达可学习非线性在规模化时受到计算预算约束。左侧是一簇数量较多、形状各异但克制的灰紫细曲线，每条都保持独立；它们接近一个狭窄的空白门槛后，不是消失，而是重新组织成右侧三条更粗、彼此仍不同但组内平行的紫色带状轨迹；远端由一块近黑偏移平面完成统一混合。两枚偏移小节点横跨重组阈值，少量短刻度在远端形成稳定回声。
Style/medium: 原创 Semantic Field 编辑插图，平面几何、轻微干式丝网颗粒、理性而有张力
Composition/framing: 精确 3:2 横图，左侧细密、中央空缺、右侧稀疏稳定，清楚但不像流程图，55–65% 留白
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，灰紫 #8879A8
Text: 无文字、无字母、无数字、无公式
Constraints: 必须表现“异质性被分组而非完全抹去”，并保留效率与表达力的张力；轨迹无箭头
Avoid: 漏斗图、压缩图标、服务器、GPU、神经网络球阵列、流程框、箭头标签、假数据、霓虹、logo、水印
