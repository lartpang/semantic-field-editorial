# 生成提示词

以下四张图使用内置 ImageGen 生成，并共享 `visual-dna.json` 中的视觉系统。

## 01 — 题图

Use case: stylized-concept
Asset type: 中文长文题图，2:1 横幅
Primary request: 为“人如何学习”创作一张独立、克制的 Semantic Field 编辑插图。核心命题不是知识被灌入，而是学习者在行动中观察自己、返回、校正，再向前推进。一个巨大的矿物蓝开口圆环作为锚点，圆环的缺口形成有意义的空白；一条近黑的细轨迹从稀疏回声刻度出发，穿过开口、回返一次后离开画面，暗示计划—监控—评估的递归；远端只有少量逐渐稳定的短条回声。两枚短注册刻度靠近关键转折。
Style/medium: 原创现代编辑插图，平面几何与轻微干式丝网印刷颜料边缘，非信息图
Composition/framing: 极宽 2:1，非对称，55–75% 留白，不超过三个视觉组，主体位于安全裁切区
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，唯一强调色矿物蓝 #5F7686
Text: 无文字
Constraints: Anchor/Trace/Void/Echo 自然融入构图；完整出版级画面；轨迹清楚但不像流程图
Avoid: 大脑、人物、书本、灯泡、齿轮、拼图、箭头标签、假数据、霓虹渐变、玻璃拟态、装饰性英文、logo、水印、随机点阵、满背景纹理

## 02 — 元认知

Use case: stylized-concept
Asset type: 中文文章章节插图，3:2
Primary request: 表达“看见自己的学习过程”以及熟悉感与真实理解之间的空缺。一个偏离中心的矿物蓝厚重开口圆盘像观察孔，但保持抽象，不画眼睛；一条近黑轨迹从圆盘内部绕行至外部，在一处大空隙前暂停，再以更清晰的方向返回；圆盘一侧的回声短条由密到疏，暗示判断经过延迟检索后被校准。关键暂停处放两枚短注册刻度。
Style/medium: 原创 Semantic Field 编辑插图，平面几何，局部轻微丝网颗粒，克制出版感
Composition/framing: 3:2 横图，非对称，大量静区，单一阅读路径，不超过三个视觉组
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，矿物蓝 #5F7686
Text: 无文字
Constraints: 体现自我观察、误判空缺和校准，不画成知识测验或流程图
Avoid: 眼睛、大脑、镜子、人物、书、考试卷、问号、标签、假图表、装饰性英文、logo、水印、随机公式

最终修订：仅移除初稿右端的显式箭头头部，替换为沿原曲线自然收细的线端；其余构图、颜色、间距与纹理保持不变。

## 03 — 自我调节

Use case: stylized-concept
Asset type: 中文文章章节插图，3:2
Primary request: 把自我调节表现为能够持续修正方向的主动学习。一块矿物蓝偏移阶梯场是锚点；一条近黑轨迹先向前、随后绕过一个明显的空白缺口，再以调整后的角度继续，形成一次明确但克制的“course correction”；三组短条回声的间距从不稳定变得有节奏，关键转弯处有两枚注册刻度。不要画三步流程，也不要使用箭头或文字。
Style/medium: 原创 Semantic Field 编辑插图，平面几何、略带颜料边缘，冷静而具有行动感
Composition/framing: 3:2 横图，主重心偏下，保留大面积上方留白，阅读路径清晰但非图解模板
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，矿物蓝 #5F7686
Text: 无文字
Constraints: 强调主动校正而非被动接受；构图与前图明显不同但保持同一系列
Avoid: 人物、道路写实场景、指南针、靶心、待办清单、箭头标签、PPT 卡片、logo、水印、霓虹色

## 04 — 既定范例与支撑淡出

Use case: stylized-concept
Asset type: 中文文章机制插图，3:2
Primary request: 准确表达新手先借助完整范例理解深层结构，再通过逐步撤去支撑走向独立解决。画面由左向右只有一条连续近黑轨迹：起点嵌在一组完整、厚重的矿物蓝阶梯框架中；中段框架逐级减少，但同一条轨迹保持连续并穿过有意义的间隙；终点只留下独立轨迹和少量稳定回声。用结构的减少表达 faded support，不画课堂场景，不加入任何数据。转折处保留两枚短注册刻度。
Style/medium: 原创 Semantic Field 解释性编辑插图，平面几何与极轻丝网颗粒，关系精确但仍像插画而非流程图
Composition/framing: 3:2 横图，左密右疏，单向清晰阅读，60% 左右安静区域，不超过三个视觉组
Color palette: 暖象牙 #F3EFE7，近黑 #1E1E1B，矿物蓝 #5F7686
Text: 无文字
Constraints: 框架支持必须连续地、逐步地减少；独立轨迹必须保持同一身份；不暗示“范例永远优于练习”
Avoid: 学生、教师、黑板、书本、数字步骤、显式箭头、标签、假公式、机械齿轮、PPT 流程框、logo、水印
